# 使用指南

## 安装

在 DeepSeek Harness 的「插件」页面选择「添加插件」，输入发布页给出的插件来源。GitHub 发布版本可使用：

```text
github:3469915488-oss/dsh-literature-hub#v2.1.3
```

安装后重启 Harness，在「已安装」中打开「文献库」开关。主侧栏会出现文献库入口。关闭开关只撤下界面、工具和后台任务，知识库内的原件、笔记、批注、录音和会话投影会保留。

## 选择 Obsidian 知识库

首次发布版默认使用 `~/Documents/Obsidian`。使用其他目录时，在 `~/.dsh/profiles/desktop/cordis.patch.yml` 的文献库条目中填写绝对路径：

```yaml
- id: literature-hub
  config:
    vaultPath: /绝对路径/我的-Obsidian-知识库
```

保存后重启 Harness。也可以在启动 Harness 前设置 `DSH_LITERATURE_VAULT`，该环境变量的优先级高于默认目录。

## 管理资料

文献库左侧是知识库的真实目录。可在任意层级创建、改名和移动文件夹。导入文件时，文件被复制到当前目录。已有 PDF、DOCX、Markdown 和 HTML 文件可直接打开。

每个文档标题旁提供「命名」和「删除」操作。命名会同步原件、关联笔记、登记、会话和文献库内部链接。删除会移入回收站，不会立即永久删除。目录菜单可打开回收站并恢复文件。

搜索默认查询当前目录当前层。文献库页面内可改为按标签、格式或内容筛选。Agent 使用 `hub_search` 时默认查询当前文献所在目录，传入 `scope=vault` 才搜索整个知识库。

## 阅读、批注与笔记

选择正文后可高亮、下划线、勾画、写旁注或向伴读提问。正文右侧的对话气泡会打开对应批注。批注面板点击引文正文可跳回原文位置。

批注和笔记是同一份记录。保存批注后，笔记页会插入可编辑的「引用内容＋笔记正文」块。删除批注或删除该引用块会同步移除另一侧关联项。引用块和录音卡都可以拖动调整笔记中的顺序。

每篇文献只维护一个 Markdown 笔记。第一次实际写入时，在原文同目录创建 `文献名笔记YYYY-MM-DD.md`，日期取首次创建日期。Obsidian 外部修改时，插件会核对版本，遇到冲突保留草稿与磁盘版本。

## 伴读与学习

伴读对话属于当前文献，选文提问会附带选中的原文和可靠页码或段落定位。模型可调用 `hub_read`、`hub_search`、`hub_notes`、`hub_annotations`、`hub_study` 和 `hub_citation` 读取或保存资料。

学习功能需要手动开始。它会保存知识地图、任务、练习反馈、错题和复习卡，离线时阅读、搜索和记笔记仍可使用。

## 布局

文献库顶部前两个按钮分别控制 Harness 工作区侧栏和文献库目录。Harness 侧栏继续显示插件、自动化任务和会话记录。目录的展开状态会被记住，窗口较窄时目录和伴读对话会变为抽屉。
